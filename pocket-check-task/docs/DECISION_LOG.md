# Decision log
- MB vs MF is measured from query choices only; no peeking or repeated looks in queries.
- No post-decision phase (the construct is worry about the future).
- A second look does not imply knowing, so re-looks are not used as the checking measure.
- Checking is read from the mouse: movement starts only after the query appears; phases are timed like VCAT (start, movement, on target, commit).
- Wider difficulty range in queries (distances 3, 6, 12, 24).
- No delays or threat manipulation in the POC. Cost/caution manipulation is parked.
- Task code is separate from analysis; legacy tasks v1-v4 are not imported yet.
